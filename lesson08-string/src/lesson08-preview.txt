A. Nhắc lại khái niệm: 
- final: final cho biến
  -> biến có từ khóa final thì mình sẽ k thể dùng toán tử = để gán lại giá trị(tại STACK).
  -> final ở STACk
  
- immutable: immutable cho object
  -> object đc gọi là immutable khi object đó đc tạo ra và lưu trữ tại vùng nhớ HEAP sau đó k thể cập nhật đc giá trị -> immutable object.
  -> để object có thể là immutable thì
     - class của nó phải có private attribute(s) và final cho attributes
     - nâng cao: private và final cho các attribute thì các attribute đó vẫn có thể cập nhật đc
      
      Item
        private final Integer id;
        private final String name;
        private final Order order; // reflection
        
        public Integer getId() {
        	return id;
        }
        
        public String getName() {
        	return name;
        }
        
        public Order getOrder() {
        	return order;
        }
