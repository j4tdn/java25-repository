A. Nhắc lại khái niệm
- final: final cho biến
  --> biến có từ khóa final thì mình sẽ không thể dùng toán tử = để gán lại giá trị(tại stack)
  --> final ở STACK
  
- immutable: immutable cho object
  --> object được gọi là immutable khi object đó được tạo ra và lưu trữ tại vùng nhớ HEAP sau đó
  	 không thể cập nhật được giá trị --> immutable object
  	 
  --> để object có thể là immutable thì
      - class của nó phải có private attribute(s) và final cho attribute(s)
      - nâng cao: private và final cho các attribute thì các attribute đó vẫn có thể cập nhật được
      
      Item
      	private final Integer id;
      	private final String name;
      	private final Order order; // reflection
      	
      	private Integer getId(){
      		return id;
      	}
