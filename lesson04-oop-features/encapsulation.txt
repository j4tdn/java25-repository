Tính chất đóng gói - Encapsulation
*********
Tính chất đóng gói được thể hiện qua các access modifier
Nêu thuộc tính, phương thức có access modifier là
- private: class
- public: project
- protected: package and external package(sub classes of current class)
- - package
V1 du:
1. Các class đóng vài trò là KDL --> cho các thuộc tính là private rõi dùng getter/setter để truy cập
2. Các hàm bên trong KDL cha nếu muốn cho KDL con trong package kê thừa --> default
ở bên ngoài package ké thừa -> protected
