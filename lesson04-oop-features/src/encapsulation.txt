Tính chất đóng gói - Encapsulation
---
Tính chất đóng gói được thể hiện qua các access modifier là:
- private: class
- public: project
- projected: current package and external package(sub classes of current class)
- default: package

VD: 
1. Các class đóng vai trò là KDL --> cho các thuộc tính là private rồi dùng getter/setter để truy cập
2. Các hàm bên trong KDL cha nếu muốn cho các KDL con trong package kế thừa --> dùng default
                                                      ở bên ngoài pakage kế thừa --> protected
